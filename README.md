# 🏦 ContaTerminal

Aplicação Java de terminal que simula a criação de uma conta bancária, coletando os dados do usuário via linha de comando e exibindo uma mensagem de boas-vindas personalizada.

## 🚀 Tecnologias Utilizadas

- **Java** – Lógica da aplicação
- **Scanner** – Leitura de dados via terminal

## 📁 Estrutura do Projeto

```
├── src/
│   └── ContaTerminal.java   # Classe principal
├── lib/                     # Dependências
├── bin/                     # Arquivos compilados (gerado automaticamente)
└── .vscode/
    └── settings.json        # Configurações do VS Code
```

## ▶️ Como Executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Lucasvr-Dev/conta-terminal
   ```

2. Compile o projeto:
   ```bash
   javac src/ContaTerminal.java -d bin
   ```

3. Execute:
   ```bash
   java -cp bin ContaTerminal
   ```

> Também pode ser executado diretamente pelo VS Code com a extensão **Extension Pack for Java**.
